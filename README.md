# NYCU Research Explorer｜研究資源探索

**從研究需求出發，找到適合自己的學術資源。**

NYCU Research Explorer 是一個研究資源探索與使用導引網站，協助國立陽明交通大學的學生與研究者，依據所屬教學單位、研究需求及研究階段，探索適合的學術資料庫與研究工具。

透過簡短的情境問答，讓研究者不必從龐大的資料庫清單中逐一尋找，也能快速找到研究的起點。

## 主要功能

- **個人化資源推薦**：選擇教學單位、回答 7 道情境題，取得「3＋2＋1」研究資源推薦，包括 3 個核心平台、2 個延伸平台及 1 個意外探索入口。
- **跨領域資源探索**：整合 22 個教學單位、33 個研究資源群組與 170 筆學術資源，涵蓋人文社會、理工資訊、生醫健康、商管財經及法律等領域。
- **研究探索風格**：依問答結果提供 4 種探索風格描述，協助使用者理解不同的研究資源探索方式。
- **研究微任務**：透過簡單的實作任務，引導使用者實際進入學術平台，開始蒐集研究資料。
- **圖書館資源連結**：串接 NYCU 圖書館 Primo 資源入口，方便進一步查詢與使用。

## 如何使用？

1. 選擇所屬學院或教學單位。
2. 回答 7 道研究情境題。
3. 查看個人化的「3＋2＋1」研究資源地圖。
4. 開啟推薦平台，完成第一項研究微任務。

也可以略過問卷，直接使用「完整平台地圖」瀏覽各類研究資源。

## 網站特色

- 無須註冊或登入。
- 支援電腦、平板與手機瀏覽。
- 提供研究資源簡介及圖書館連結。
- 問卷回答不會傳送至伺服器；最近一次探索結果可儲存在使用者的瀏覽器中。

## 使用提醒

本網站提供研究資源探索與使用導引，推薦結果僅供參考，不代表研究能力或人格特質評量。

部分學術資源需具備學校授權或符合特定存取條件，實際使用方式及可用範圍，請以[國立陽明交通大學圖書館](https://www.lib.nycu.edu.tw/)公告為準。
